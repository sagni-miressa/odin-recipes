Odin Recipes

A simple recipe website built as part of The Odin Project Foundations Course. This project demonstrates basic HTML skills, including creating web pages, using links, working with images, and structuring content with lists and headings.

🚀 Live Demo

https://sagni-miressa.github.io/odin-recipes/ (update with your GitHub Pages link if different)

📖 About The Project

The Odin Recipes project is the first project in The Odin Project curriculum. It consists of a homepage that links to multiple recipe pages. The goal is to practice:

HTML document structure
Headings and paragraphs
Lists (ordered and unordered)
Links and navigation
Images
File organization
🛠️ Built With
HTML5

Installation
Clone the repository:
git clone https://github.com/sagni-miressa/odin-recipes.git

Navigate to the project folder:
cd odin-recipes

Open index.html in your browser.
